# Crittografia

Raccolta di materiali, esercizi, script e notebook sviluppati per il corso di Crittografia.

## Contenuti della cartella

### 1. Generatore di Geffe e Attacco di Correlazione

* **Descrizione:** 
  * **Esercizio 4.18** (dal libro di testo _Paterson e Stinson, Cryptography, Theory and Practice, Fourth edition_): Studio analitico della funzione combinante di Geffe e calcolo delle probabilità di correlazione tra i singoli ingressi e l'uscita.
  * **Implementazione pratica:** Realizzazione in Python del **Generatore di Geffe** basato su 3 registri LFSR per la cifratura e la decifratura di messaggi.
  * **Attacco:** Simulazione di un attacco di correlazione a chiaro noto.

* **File disponibili:**
  * `geffe_generator.ipynb`: Notebook interattivo per l'esplorazione teorica e la simulazione passo-passo.
  * `geffe_generator.py`: Script Python standalone, ideale per l'esecuzione diretta da riga di comando senza la necessità di Jupyter o Google Colab.
